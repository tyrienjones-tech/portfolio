PC_HEALTH

FINISHED v0.1.0 IN DAILY USE MIT LICENSED
SCREENSHOT · PC_HEALTH SNAPSHOT / MCP OUTPUT

A longevity monitor for Windows PCs.

The job. Watch the health of a Windows PC over time — drive wear, temperatures, GPU, and system errors — and keep a timestamped record so you can see trouble coming before a drive dies on you. Read-only by design: there’s exactly one network call in the whole tool, to a sensor service on my own machine. Nothing leaves the box.

What’s mine. The layer on top of the sensors: polling four sources on a sensible schedule, deciding what counts as healthy versus worrying, writing clean timestamped JSON snapshots — and handing it all to an AI through an MCP server with five typed, read-only tools.

02

ETS2LA — also running now

Fixing a four-year-old self-driving mod from the ground up, and keeping it in Python.

ETS2LA is a self-driving mod for Euro Truck Simulator 2. The upstream team is rewriting it in C#, citing performance, maintainability, and code quality. I checked — fifty analysis passes through the codebase — and those reasons don’t hold up. The bugs people actually hit are discipline-and-pattern bugs that come back one-for-one in C# unless you fix the pattern first. This is my own campaign, not a pull-request job: the mod is theirs, GPL v3; the campaign and the argument are mine.

“Write like you’re explaining the fix to a foreman, not pitching to a board.”
THE RULE THE REPORT OPENS WITH
BUG LEDGER · 4 CLOSED LAST UPDATED MAY 31
ETS-021/022
Arbitrary code execution through the settings file The loader ran pickle.loads(eval(value)) on text read straight out of SQLite. Replaced with json.loads; eval and pickle removed from that path. Verified with a hostile-input round-trip test and an in-game window-drag.
ETS-024
A second code-execution hole, in the model-file loader eval() on the contents of a model file. Swapped for ast.literal_eval. Supply-chain reachable — a poisoned model file would have run on the next update check.
ETS-023
Window position that never saved A function that recorded window position was never called. Dead since at least August 2025. Two-line fix, verified in-game.
ETS-005
Map page froze on the second open Stale websocket subscription state that never reset on close. Three-line fix, verified in-game.

How I run it. Four roles: a Director (Talos) for strategy and scope, an Auto Drive Agent that proposes and lands fixes in the working copy under my checkpoints, an Auto Drive Strategist for a second opinion each cycle — and me as operator, routing between them and driving every fix in-game before it counts as done. Kanban board, append-only JSONL ledger, session logs, handovers.
