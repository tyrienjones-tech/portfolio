01

The result

I built it to run anywhere, and it does. It started self-hosted on hardware I control, behind locked-down security headers and a strict content policy, and scored an SSL Labs A+. I did that to prove I could. Then I moved it to Cloudflare Pages: same files, nothing rewritten, the security certificate renews itself, and an update is one push to GitHub.

The same strict security headers and content policy now ship from a plain headers file in the repo, so anyone can read exactly what the site sends.

Fast, private, and boring on purpose. Nothing fragile, nothing to break, nothing phoning home.
